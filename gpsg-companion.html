Stage 1: Attribute Assignment

📖 Character Creation Tips:
• Start with 25 in each attribute and 40 points to distribute
• You can lower up to 4 attributes below 25 to gain extra points
• Attributes cannot exceed 40 during initial creation
• Attribute Bonus = Tens Digit (e.g., 30 = +3, 39 = +3, 40 = +4)
• Skill Bonus = 5 × Skill Rank (e.g., Rank 3 = +15)
• Higher attributes in Agility, Strength, and Endurance improve combat effectiveness
• Intelligence affects your starting languages
• Willpower is crucial for resisting mental effects

Stage 3: XP Spending

📖 XP Spending Guide:
Starting XP: 2000

Bonuses:
• Attribute Bonus = Tens Digit (e.g., 30 = +3, 39 = +3, 40 = +4)
• Skill Bonus = 5 × Rank (e.g., Rank 3 = +15)

XP Costs:
• Attributes: 100 XP per point (up to 40), then 200 XP per point (41-50)
• Skills: 100 XP for rank 0, then 50 × (rank being bought) for each subsequent rank
  (You must have the previous rank to buy the next)
• Talents: Tier 1 = 200 XP, Tier 2 = 400 XP, Tier 3 = 600 XP
